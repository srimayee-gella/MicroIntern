# MicroIntern 🎓💼
> **Real Projects. Real Experience. Your Flexible Opportunity.**

MicroIntern connects **college students** with **small businesses and startups** for short-term, skill-based project sprints (2 to 7 days).

---

## 🌟 The Problem & Solution

* **The Student Challenge:** Long-term 3–6 month internships are rigid and conflict with college semesters, exams, and classes. Students graduate with theoretical grades but lack verified proof-of-work.
* **The Startup Dilemma:** Small businesses and early-stage startups frequently need help with small, focused tasks (React UI components, bug fixes, Canva reels, Excel cleanups, SEO copywriting) but cannot afford full-time salaries or agency retainers.
* **The MicroIntern Solution:** Bite-sized micro-internships with transparent milestone pricing in Indian Rupees (₹), escrow protection, verified employer ratings, and verifiable digital certificates.

## 💻 Tech Stack

* **Frontend Framework:** React 18 with Vite 5
* **Styling:** Tailwind CSS with custom branding, responsive layouts, and soft shadows
* **Icons:** Lucide React
* **Effects:** Canvas Confetti (for application submissions and project completions)
* **Storage & State:** Context API with persistent `localStorage` synchronization

## 🔑 Key Features & User Flows

1. **Modern Landing Page:**
   * Text-based MicroIntern logo with student-business connection icon
   * Hero section with animated statistics counters (1,000+ Students, 250+ Businesses, 500+ Projects, 10+ Skills)
   * 3-node interactive illustration (`Student → MicroIntern → Business`)
   * Problem breakdown (*For Students, For Businesses, The Gap*)
   * 4-step connecting timeline (*Create Profile → Discover Projects → Apply & Work → Earn & Build Experience*)
   * Featured opportunities carousel and real student/founder testimonials

2. **Find Projects & Dynamic Filtering:**
   * Instant search across titles, skills, and companies
   * Multi-facet filters: Skill, Category, Duration, Budget (₹), Work Type (Remote/Hybrid/In-Person), Difficulty Level
   * Real project cards with tags, stipend, duration, and save/apply actions

3. **Project Details & Application Flow:**
   * Comprehensive specifications, requirement checklists, and deliverables
   * One-click "Apply Now" with pitch cover note and availability confirmation
   * Confetti celebration and real-time toast feedback

4. **Student Dashboard:**
   * Welcome banner, statistics cards, and recommended projects
   * Application status tracker (*Applied → Under Review → Accepted → Completed*)
   * Active sprints view with deliverable handover modal
   * Completed projects with verified reviews

5. **Verifiable Digital Certificates:**
   * Realistic digital certificate viewer with official crest, ID stamp, verification URL, and authorized signatures
   * Built-in PDF print and download capability

6. **Earnings & Escrow Payouts:**
   * Total Earnings: ₹8,500 | Pending: ₹2,000 | Completed: ₹6,500
   * Transaction history table with reference IDs
   * Instant UPI withdrawal request modal

7. **Student Profile & Portfolio:**
   * Full profile with university degree, verified skills, availability, and client reviews
   * Interactive "Edit Profile" modal to add/remove skills and links

8. **For Businesses Page:**
   * Value proposition (*Affordable, Flexible, Quick hiring, Skilled students, Short-term commitment*)
   * Comparison matrix: Traditional Internships vs. Agencies vs. MicroIntern

9. **Post a Project with Live Preview:**
   * Real-time form with duration, category, deliverables, and ₹ stipend
   * Split-screen / live card preview showing how students will view the listing

10. **Business Dashboard:**
    * Statistics: Active Sprints, Applications, Completed Projects, Total Paid Out
    * Candidate review modal with portfolio links and 1-click **Accept & Hire** / **Reject**
    * Milestone sign-off with 5-star rating modal and automatic escrow release

## 🛠️ Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the Vite development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build
npm run preview
```

The application runs on `http://localhost:3000/`.
